# Colosseum Battle Environments 1.6.1

Drag the repository/release ZIP into the Gen1Recomp launcher as a normal mod. CBE supports Gen 1 and Gen 2.

CBE requires a user-supplied **Pokemon Colosseum (USA) GC6E01** disc source. On a representation-aware Gen1Recomp launcher, a valid raw ISO/GCM, safely scrubbed/trimmed raw image, or GameCube CISO can be accepted by structural disc validation; the filename extension itself is not important to CBE. Older launchers remain compatible with the canonical ISO hash and the tested GC6E01 CISO hash declared in `manifest.json`.

The Colosseum audio cache is optional. If the platform cannot render it, or one/more generated audio files fail validation, CBE continues to run its arenas, models, MoveFX, cameras, trainers, capture presentation, and transitions and falls back to the original game audio where needed.

See `CBE_1.6.1.md` for the release changes and `VALIDATION_1.6.1.md` for the package/source checks.
